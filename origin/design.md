Poetic Typewriter (诗意打字机) - 项目交接文档

1. 需求设计文档

1.1 产品愿景

打造一款极具诗意和沉浸感的拟物风打字游戏。通过将输入的字符实体化为“随风摇曳的气球”，结合复古打字机的视觉元素，为用户提供一种减压、唯美的文字输入体验。

1.2 核心机制

目标文本：屏幕上方显示预设的英文短诗句（20句循环），作为玩家的输入目标。

拟物输入：提供屏幕底部的拟物风虚拟键盘，同时支持物理键盘输入。按键需有真实的下压物理反馈。

字符升空（气球机制）：

每当用户输入一个正确或错误的字符，该字符会从打字机出纸口升起。

字符底部连着一根具有弹性的细线（基于贝塞尔曲线），像芦苇或气球一样在空中随风摇摆。

起线点映射：连线的起点根据字母表顺序（a-z）在出纸口自左向右均匀分布，形成类似“织布机”或“竖琴”的视觉美感。

删除惩罚（物理拉回）：按下退格键时，悬浮的字符会被细线迅速“拉回”机体内部并销毁。

通关特效与时序：

整句输入完成后，锁定输入。

等待期：等待画面中最后一个字完全升空并进入摇摆状态（+1秒额外欣赏停顿）。

收线期：所有字符底部的细线向上收缩消失，字符进入短暂的无氧悬浮状态（1.5秒）。

消散期：字符受到水平向右的风力和微弱上下浮动影响，缓慢向右飘散，透明度逐渐降低并伴随模糊效果，直至完全消失。

2. 开发文档

2.1 技术栈

核心：HTML5, CSS3, 原生 JavaScript (Vanilla JS)。

样式框架：Tailwind CSS (通过 CDN 引入，用于快速构建响应式布局)。

无外部构建依赖：纯单文件运行，降低维护成本。

2.2 核心模块说明

本游戏主要由以下几个核心逻辑模块构成：

PretextEngine (模拟重排引擎)：

功能：负责解析目标文本并将其打散为独立的 span 标签。利用 getBoundingClientRect 高效提取每个目标字符在屏幕上的绝对物理坐标。

作用：为气球字符的上升提供精确的目标终点定位。

输入捕获模块：

监听 keydown 事件（物理键盘）。

监听 touchstart 和 mousedown 事件（虚拟键盘），并提供激活状态的 CSS 类切换以实现视觉反馈。

SVG 动态渲染器：

使用 <svg> 和 <path> 标签实时绘制牵引线。

updatePath 函数通过计算起点和终点的中点，加入基于时间正弦波 (Math.sin) 的偏移量作为控制点，生成动态二次贝塞尔曲线，模拟被风吹弯的弹性视觉。

自定义物理与动画引擎 (gameLoop)：

基于 requestAnimationFrame 的主渲染循环。

个体状态机 (Balloon State): 管理单个字符的生命周期：rising (上升) -> swaying (摇摆) -> falling (被删除拉下) -> success_retracting (成功收线) -> hovering (悬浮) -> blowing_away (物理吹散) -> dead (销毁)。

全局状态机 (Game State): 控制游戏宏观节奏：typing (输入中) -> waiting_to_rise (等待升起) -> waiting_to_retract (等待收线) -> retracting (收线中) -> hovering (悬浮中) -> blowing (吹散中)。

3. 美术约束 (Art Constraints)

3.1 视觉风格

整体基调：暗色模式 (Dark Mode)，复古拟物 (Skeuomorphism)，静谧诗意。

背景：深灰/炭黑色 (#1a1a1a)。

3.2 字体规范

全局与 UI：Playfair Display（带有一点优雅文学气息的衬线体）。

打字机按键与漂浮文字：Special Elite（经典的打字机等宽字体），以增强真实感。

3.3 拟物材质与光影

打字机机体：使用多重 box-shadow（包含阴影、内发光、底部暗角）和线性渐变 (linear-gradient) 塑造厚重的塑料/金属质感。

按键：

圆形按键，采用径向渐变 (radial-gradient) 模拟球面反光。

包含微小的银边装饰（伪元素 ::before 配合 inset）。

交互反馈：:active 状态必须有明确的 Y 轴位移 (translateY(3px)) 且阴影需相应缩小，以模拟真实的物理按压行程。

3.4 动画约束

禁用过度使用 CSS Keyframes：为了确保“随风飘散”和“连线摇摆”的随机性和物理真实感，核心位置变换必须在 JS 中通过逐帧计算 transform 实现，CSS 仅负责静态的 transition（如按键按压、提示文本的淡入淡出）。

5. 项目启动方式

由于项目采用了极致轻量化的单文件架构（无构建工具依赖），启动与开发极其简单：

5.1 快速预览

找到项目根目录下的 index.html 文件。

直接双击使用任何现代浏览器（推荐 Chrome, Edge, Safari）打开即可体验完整游戏。

5.2 开发调试

虽然双击可以直接运行，但为了避免未来引入本地字体、音效或图片时触发浏览器的跨域限制 (CORS)，推荐使用本地服务器环境启动：

使用 VS Code：安装 Live Server 插件，在 index.html 文件中右键点击 "Open with Live Server"。

使用 Python：在终端进入文件所在目录，运行 python -m http.server 8000，然后在浏览器访问 http://localhost:8000。

使用 Node.js：使用 npx serve . 等轻量级静态服务器。
